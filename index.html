HOW THE RESULT IS CALCULATED

Traceable scoring, with no hidden model

  1. 1Compare each reading Normal-band readings score 100. Values between warning and critical limits decline linearly toward zero.
  2. 2Weight engineering significance Capacity, safety, protection, and core performance signals carry more influence than contextual counters.
  3. 3Apply hard safety gates A critical safety-tagged result forces the overall result to Critical even if the weighted average is high.
  4. 4Report evidence coverage Missing readings do not count as healthy. Fewer than four readings returns Insufficient data.

Default limits are a generic LFP utility-scale screening profile, not design limits. Replace them with approved cell, rack, PCS, transformer, fire-system, site, warranty, commissioning, and grid-code limits before using the result in an engineering decision.
